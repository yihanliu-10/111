# 乳腺钼靶(Mammography)域偏移研究构思

## ★★ 最终流程(v15):FlowBayes 全管线

**目标:乳腺钼靶模型跨数据集/设备部署下的分类、校准、弃权一体化;source-free、模型冻结。**

### 训练期(源域,一次性)
- **S0 数据**:5 公开集(VinDr/RSNA/CMMD/INbreast/CBIS-DDSM),乳腺区裁剪、长边 1536、检查级标签、病人级切分,保留厂商元数据;
- **S1 表征**:合并训 backbone(EffNet-B2/ConvNeXt-T),判别头保留(基线+混合架构主通道),冻结;
- **S2 特征库**:全源前向存特征(~50万×512)+ 白化统计;
- **S3 生成引擎(唯一新增训练)**:类条件 CFM v_θ(x,t,y),y∈{良,恶,∅}(classifier-free dropout)。**一网三用**:类条件似然×2、无条件场(边缘似然+回流)。纯回归,小 MLP,单卡数小时;
- **S4 校准件**:典型集统计(弃权阈 τ)、各类似然参考分布、温度校准;安全性检查(留一源集作假目标域,恶性预测不得向良性漂)。

### 部署期(每张图,零训练)
- **T1** 特征 z = whiten(backbone(img));
- **T2 数据集级审计**(新站点首批无标签图跑一次):边缘似然分布→协变量偏移程度;BBSE→π̂;输出"偏移体检报告"(交付物,站点验收测试),决定 T3 开关;
- **T3 回流(可选)**:z 沿无条件场回源流形,score 范数刹车;
- **T4 似然**:PF-ODE(FM 直轨迹 5–10 步)一次积分批量出 log p(z|恶)、log p(z|良)、log p(z);
- **T5 决策**:log p(z)<τ → 弃权转人工;否则 p(恶|z) ∝ p(z|恶)·π(π=部署人群患病率),输出诊断分+逐例偏移严重度。

### 评测协议
主实验 leave-2-out ×10;基线:pooled ERM 判别头、BN-adapt、TENT(预期崩)、直方图匹配、DDA 像素版;指标:AUC、sens@90%spec、ECE、risk-coverage、密度分层、微钙化子集;消融:FM vs score、回流开/关、换先验、刹车 vs 固定步、生成/判别/混合。

### 里程碑
W1–2 S0–S1+掉点表(**go/no-go:≥5 点**)→ W3 便宜基线 → W4–7 S2–S4+T3–T5+安全检查 → W8–10 全矩阵+消融 → W11–12 写作(MICCAI 保底,TMI 叙事)。

## 定稿主线(v9,历史):特征空间"流形回流"分类(现为 v15 的 T3 模块)

**最终目标 = OOD 数据集上的分类性能;OOD/ODE/似然全部内化为提升分类的手段。**

**管线(四部件)**:
1. **冻结分类器**:5 源合并训 backbone + 分类头(同时即 pooled ERM 基线);
2. **回流模块(核心,ODE 所在)**:5 源特征空间训 score 模型定义 PF-ODE;OOD 特征沿 dx/dt = ∇log p_src(x) 流回源流形数步,再入冻结分类头。特征空间版 DDA,mammo 高分辨率下算力现实;
3. **似然停步准则(数学卖点)**:流到该样本 PF-ODE 似然进入源域典型集即停——似然是回流强度的自适应控制器,非独立贡献;
4. **患病率先验重校准 + 选择性预测(临床卖点)**:回流后似然仍极低者弃权转人工;报全量 AUC 与弃权 5% 后 sensitivity@specificity 两版。

一句话:用源域概率流把 OOD 特征运回分类器的可靠区,似然决定运多远,运不回的交给人。

**执行计划(12 周)**:
- W1–2|钉死问题:5 公开集(VinDr/RSNA/CMMD/INbreast/CBIS-DDSM)合并训 EfficientNet-B2 级分类器,leave-2-out 测 ID vs OOD 掉点。**Go/No-Go:掉点 <3 点换方向,≥5 点方法空间充足**;
- W3|便宜基线天花板:BN 重估、直方图匹配、阈值重校准、TENT(预期崩,崩即论据);
- W4–7|回流模块:源特征训 score 模型 → ODE 回流 → 扫步数/强度 → 似然停步。**安全性检查:回流不得把病例推过分类边界**(留出源域带标签验证,此为唯一致命坑);
- W8–10|全矩阵(10 组合)、消融(固定步长 vs 似然停步、有无重校准)、选择性预测曲线;
- W11–12|写作,目标 MICCAI/TMI。

**既有讨论归位**:TENT 失效分析→动机;E′ Wasserstein 理论→回流的理论解释(沿 W₂ 测地线向源分布移动);似然分解→弃权机制;CLIPTTA/DDA/DoSReMC→相关工作。以下各方案(A–F)保留为过程记录与备选。

### 论文形态定位(v10):TMI 式"统一框架",范本 Wang et al. arXiv:2508.08660
范本的五要素:①指出方法论分裂(source-accessible 靠对齐 vs source-free 靠伪标签,均缺显式跨域知识构造);②统一本体(域无关概率流形);③解耦表示(规范内容 + 个体变换);④适应性为架构内生性质;⑤流形遍历作可解释性卖点。
**我们的映射**(内核不变,叙事升格):
- 本体:5 源学**规范乳腺影像特征流形**(score 模型的高密度区);
- 解耦:特征 = 流形上规范内容(病灶/腺体)+ 离流形位移(厂商指纹);
- 适应内生:ODE 回流 = 流形检索操作,新域零训练;
- 统一四能力:source-free 回流(主线)、source-accessible 训练正则(域泛化)、OOD 检测(似然/距离)、偏移严重度(路径长度);
- **新增模块**:轻量解码器做流形遍历可视化——沿域位移方向走,风格连续变化而肿块/钙化不动(封面实验,兼答安全性质疑)。
**代价与策略**:工作量 +1/3(解码器 + source-accessible 变体),周期 12 周 → 5–6 月,档次 MICCAI 短文 → TMI/MedIA 长文。执行顺序不变(W1–2 基线照跑),写作素材即日起按"规范流形框架"组织;可解释性解码器排在方法验证成功之后。进可攻 TMI,退可守 MICCAI。

### 方案 G(v12 主线候选):FlowBayes——表征空间精确似然生成式分类
**反转**:弃判别头 p(y|z),为每类训特征空间 score 模型建模 p(z|y),PF-ODE 精确算类条件似然,贝叶斯出分类:p(y|z) ∝ p(z|y)·π_y。
**一个模型五个读数**:①分类=后验;②患病率偏移=换先验 π(筛查 0.7% vs 诊断 30%,改一个数零重训);③OOD/弃权=边缘似然 p(z)(同一次积分副产品);④设备偏移修复=无条件回流作可选前置(原定稿降级为模块);⑤域偏移概率审计=分别量测 p(z)/π/p(z|y) 各变多少——首次把域偏移拆成三个可测数。
**为什么不普通**:生成式分类器抗偏移有经典理论(Ng & Jordan 2001;扩散版 "Secretly Zero-Shot Classifier" 已验 ImageNet-C),但全在像素空间、靠 ELBO 采样、千次调用且随机;我们特征空间 512 维 + PF-ODE 精确似然 = 确定性毫秒级——解决"生成式分类美而不实用"的十年痛点,代差而非增量。临床根:患病率先验与弃权是构造本身而非补丁。叙事:一个概率本体长出分类/校准/检测/修复/审计,TMI 式统一框架。
**风险对冲**:①生成式 ID 精度略输判别式 → 混合架构:判别为主、边缘似然报警时生成式接管(切换机制本身是贡献点);②恶性样本少 → 共享主干、类别条件化(classifier-free 式);③W1–2 go/no-go 不变,升级不推翻已排工作。
**待查**:特征空间 diffusion classifier + 域偏移是否已有(像素空间已有,表征空间 + 医学 + 患病率显式待确认)。

**双硬性要求对照(v13,G 定为主线)**:
- **医学意义四支柱**:①跨站点失效是商用乳腺 AI(Lunit/Transpara 外部验证滑坡)采购级障碍,本方法免重训免本地标注恢复性能;②显式先验 π 正中 FDA predetermined change control——换人群=改一个数、模型零变更,可论证不触发重新审批(独有卖点,临床审稿人语言);③边缘似然弃权=运行时"已知局限性声明"的可执行版,radiologist-in-the-loop 机制化;④测试时冻结=唯一监管可行的 TTA(对比 TENT 类不可审计)。**达标前提**:主指标 sens@90%spec+召回率影响、密度分层、微钙化子集、ECE、risk-coverage,第一天起按此设计;
- **新颖性四空位**(三轮查证):①表征空间精确似然生成式分类(像素空间 ELBO 版已有,代差在确定性毫秒级);②检测→修复→分类闭环(轨迹 OOD 10+ 篇全止步报警);③域偏移概率审计(p(z)/π/p(z|y) 三分量首拆);④mammo 模态空。**动笔前必查**:表征空间 generative classifier 抗偏移是否被占;精读 2510.17381。窗口在收窄,执行速度即保鲜剂;
- **决策**:G 为主线,原定稿(回流)降为 G 的前置模块与消融;两者共享 W1–2 基线与全部配方,切换成本≈0。

**v14:似然引擎换为 flow matching(FM)**。此前"FM 需两端点"的否决只针对跨域桥用法;FlowBayes 中 FM 两端 = N(0,I) ↔ 源类条件特征分布,均已知。训练:CFM 纯回归(x_t=(1−t)z₀+tz,回归 v_θ(x_t,t,y) 到 z−z₀)。优势:①OT 路径近直线,精确似然 5–10 步(score 版需 30–50),推理砍 3–5 倍;②无多 σ 调参;③流映射给出"高斯化坐标系"——源域≈N(0,I),该空间中 Mahalanobis 首次有原则(可单写一节)。引擎分配:类条件/边缘似然=FM 默认、score 作消融;回流修复保留 score 退火版(FM 缺目标端点问题仍在;"风格扰动→干净"模拟偏移桥作扩展);解码器可视化用 FM 采样。**新增必查**:flow matching 当分类器(条件 FM 似然分类)是否被占;若像素空间有,仍占表征空间+医学+显式先验格子。

### 方向决策记录(v11):RLVR 备选评估 → 维持 mammo 主线
RLVR 的时间成本三层:单次实验 8×A100 数天–数周(rollout 瓶颈);基建 2–4 周(vLLM+verl/OpenRLHF+奖励校验器,RL 不稳定);赛道最卷、被抢注期望损耗最大。对比本项目:核心训练单卡数小时,竞品格局清晰,12 周单人单卡可到初稿——迭代周期差两个数量级。且本项目尽职调查已完成,换向即清零。
**决策**:mammo 按计划执行;RLVR 只读不动手(便宜切口如数据侧/价值侧分析适合入组有算力积累后作第二项目)。若 W1–2 go/no-go 失败再评估转向,届时仅损失两周。

### 通俗版:五步
1. **训一个普通分类器**:5 源合并正常训"良/恶"分类模型,训完冻结,再也不动;
2. **记住正常特征长什么样**:5 源全部图过 backbone 收特征,在特征上训小 score 模型——给"分类器熟悉的地盘"画地图;
3. **新数据的特征搬回熟悉的地盘(ODE)**:OOD 特征沿 dx/dt = ∇log p(x) 往概率上坡挪,挪回源域高密度区,再喂冻结分类头。不改模型,改输入;
4. **似然当刹车**:每挪一步顺带算似然,升回源域正常水平即停——挪少洗不净,挪多洗掉病灶,刹车自动;
5. **搬不回来的交给人**:似然怎么都上不来的病例弃权转人工;报全量 AUC 和弃权 5% 后的敏感度/特异度两个数。

评测:5 集轮流留 2 当 OOD(10 组合),每次比三个数:不处理 / 便宜基线(BN 重估等)/ 回流方法。前两步是准备,第 3 步是方法本体,第 4 步是数学卖点,第 5 步是临床卖点。

### 回流 ODE 的数学身份与先行研究
**解什么**:初值问题 dx/dt = ∇log p_src(x),x(0)=OOD 特征——沿源密度上坡走进高密度区。四个等价身份:①对数似然连续梯度上升(驻点=源分布 mode);②Langevin 动力学零温极限;③mean-shift 连续版(1975 经典,密度梯度换成学习的 score);④Wasserstein 梯度流(能量 F(μ)=E_μ[−log p_src],接 E′ 的 OT 理论)。
**实现要点**:裸密度 ∇log p 高维病态 → 用噪声条件 score,从大 σ 到小 σ 退火 = 反向 PF-ODE = Tweedie 去噪(把域偏移当噪声去掉)。
**先行研究**:mean-shift(Fukunaga 1975; Comaniciu & Meer 2002);Song & Ermon score/PF-ODE(生成用途);DiffPure(ICML 2022,对抗样本投影回流形再分类);DDA(CVPR 2023,损坏图像流回源分布做 TTA,像素空间);梯度流 GDA(ICLR 2024);PF-ODE 似然 OOD(SCIA 2025)。
**新颖性组合**:特征空间 × 跨数据集医学域偏移(非对抗/合成损坏)× 似然自适应停步 × 乳腺癌分类服务——四要素组合为空位。

### "ODE 做 OOD"赛道密度报告(2026-08 三次查证)
- **大圈**(扩散做 OOD/异常检测):拥挤,已有综述(ACM CSUR 2025;DMAD;医学 OOD 综述 2404.18279);
- **中圈**(ODE/轨迹统计量当 OOD 分数):10+ 篇且加速(2405.11881、2504.07793、DiffPath 2508.15737、SCOPED 2510.01456、多统计量 2510.17381、CNF 2606.00684、2512.18454、GEPC 2602.00191、2605.11014、2605.20502)——**纯"新轨迹统计量做检测"窗口正在关闭,勿入**;
- **医学圈**:2507.23411(MICCAI 2025 UNSURE,前向轨迹做病理异常评分,5 步)——做的是语义异常(找病灶),非设备/数据集偏移,未占我们格子;另有稀疏 CT、胎儿超声散点;
- **内圈**(mammo × 设备偏移 × 回流救分类):空。
**结论**:检测者众、修复者寡——站位必须是"轨迹当修复算子"(回流救分类),检测仅作弃权模块。**撞车预警**:2510.17381 与"风格/语义分解归因"相近,动笔前精读;若重叠,分解部分收缩为引用 + 只做修复。

### 竞品定位(闭环)
**一句话:我们 = 特征空间的 DDA + 逐例似然刹车。**
正面竞品(测试时修输入、模型冻结,同任务同哲学):DDA(CVPR 2023,像素空间扩散投影回源,ImageNet-C);SDA/Everything to the Synthetic(CVPR 2025,对齐到合成域);SteeringTTA(2025,引导扩散轨迹);DiffPure(ICML 2022,对抗扰动版);皮肤镜/病理/眼底三篇(竞品的医学分支,均像素空间)。
**对 DDA 家族的三个战场**(骨架实验):①算力——像素空间扩散在 2–4K 钼靶上训练多卡数天/推理每图数秒,我们单卡数小时/毫秒级,差 2–3 个量级;②微钙化——像素去噪抹高频,微钙化子集敏感度对比,竞品失败模式即我们论据;③适应量——竞品全局固定噪声深度,我们逐例刹车,消融可验证。
**待确认**:"特征空间 score 回流 TTA"暂未搜到占坑者(最近为 VAE 潜空间对齐零星工作),动笔前以 "feature-space diffusion TTA / latent purification" 复核;若被占,差异化收缩为 mammo + 似然刹车 + 弃权。

### 医学影像内的近亲与收窄后的新颖性(2026-08 二次查证)
**已存在**("扩散投影回源域再分类"已进医学影像,均为图像空间):皮肤镜(arXiv:2405.11289,低通滤波结构保持);病理染色 TTA(ECCV 2024,染色偏移作非线性逆问题);眼底连续 TTA(MICCAI 2025)。通用视觉 diffusion-TTA 已成分支(DDA、arXiv:2312.05274、SteeringTTA);特征级投影有零星工作(生成式特征投影、LA-VAE)。→ 范式可行性已被三个模态验证;大标题已被占。
**收窄后的四条差异化**:
1. **模态空位**:mammo 无人做(仅 DoSReMC 的 BN 适应);且 2–4K 分辨率 + 数十微米微钙化使图像空间扩散既贵又险——现有方法直接搬运预期翻车,反推特征空间必然性;
2. **特征空间 score 流** vs 图像空间扩散:便宜一个量级、确定性、单图可用;图像空间版本作对照(其失败即论据);
3. **似然控制逐例停步 + 弃权**:三篇近亲均为固定噪声注入深度;
4. **设定**:多源(5 集)× 数据集级设备+人群混合偏移 × 患病率校正 × leave-2-out。
**行动**:三篇近亲升格为必打 baseline(至少复现皮肤镜管线于 mammo);方向正在变热(MICCAI 2025 已入场),W1–2 基线实验勿拖。

### 训练配方(三件事,测试时零训练)
1. **训分类器**:5 源合并,常规监督训练(backbone → 特征 → 分类头,交叉熵),收敛后全部冻结;
2. **倒特征**:冻结 backbone 对 5 源全部图像前向一遍,存特征矩阵(~50 万 × 512),即"源特征云";
3. **训 score MLP**(唯一新增训练,单卡数小时):输入(特征, σ),输出方向向量。每步:抽特征 z → 抽 σ → z̃ = z + σε → loss = ‖MLP(z̃,σ) − (z−z̃)/σ²‖²。直觉:随手把源特征推离云,罚网络指出回家的路;σ 大练远程方向,σ 小练末段精修。
不需要目标域数据/额外标注/图像生成。测试时:新图提特征 → 反复查 MLP 挪步(σ 退火)→ 似然达标停 → 喂冻结分类头。对应计划:1、2 = W1–2,3 = W4。

### ODE 模块实现配方(~300 行)
- **前处理**:源特征白化;score MLP(3–5 层×1024,σ 用 Fourier 嵌入)在白化空间训,σ ∈ [0.01, 1] 对数均匀;
- **回流循环**:σ 由 1.0 → 0.01 geomspace K≈20–50 步;每步 z ← z + η·σ²·s_θ(z,σ)(Tweedie 去噪跳,η≈0.1–0.5);Euler 足够,精致可换 Heun/RK45;
- **刹车(便宜代理)**:score 范数当海拔计——部署前存源验证集各 σ 档 ‖s_θ‖ 分位区间,测试时落入区间即停(零额外成本);
- **精确似然只用两处**:弃权判定(增广 ODE + Hutchinson,log p < 源验证集 P1 → 转人工)与"似然停步 vs 固定步数"消融;
- **必做实验**:固定步数 vs 自适应刹车;安全性检查(留出源集作假目标域,回流不得使恶性预测向良性漂);步长/K/σ 敏感性分析。
- 工作量:score 训练 ~150 行(单卡数小时)+ 回流 ~50 行 + 刹车统计 ~30 行 + 增广似然 ~60 行;推理每图毫秒级。

### 与 flow matching 的区别(预期审稿问题)
同族:都是"学矢量场 + 解 ODE 搬运样本"。三点差异:
1. **学的对象**:FM 学速度场(走法,为 A→B 传输专门回归);score 学密度梯度(地形),搬运是测试时借用;
2. **端点(关键)**:FM 训练时须指定两端分布 → 目标域数据必须在手、每个新域需重训桥(MedShift 即此类);本方案只建模源端 → **source-free,未见域零训练即来即用**;
3. **时间/终点**:FM 全程走满固定插值时间;本方案积分时长由似然刹车逐例决定。
**对照实验设计**:FM 桥(需目标域无标签数据,轨迹直、步数少)vs score 回流(零目标数据)——量化"为未见域即插即用牺牲多少精度",将方法定位从"另一种流"提升为部署成本-精度权衡的回答。

## 1. 问题背景

钼靶癌症检测/分类模型在跨域部署时性能显著下降,偏移来源可分为两类:

- **采集偏移(acquisition shift)**:厂商(Hologic / GE / Siemens / Fuji / IMS)、探测器、剂量、压迫厚度,尤其是各家 "for presentation" 后处理差异巨大;数字化胶片(DDSM)与 FFDM、DBT 合成 2D(C-View)差异更大。
- **人群偏移(population shift)**:乳腺密度分布随人种/年龄差异明显(亚洲女性致密型比例高),患病率与病灶谱系也不同。

已知经验现象:跨域时 AUC 掉 5–15 点;**校准崩得比排序更狠**——AUC 尚可但工作点阈值失效,对以"召回率达标"为硬约束的筛查流程是致命的。

## 2. 三个候选切入点

### A(推荐):多视角一致性驱动的测试时适应 + TTA 失效分析

**两个贡献点:**

1. **失效分析**:筛查数据癌症患病率 <1%。TENT/MEMO 等基于熵最小化的 TTA 在极端类别不平衡下会把全部样本推向多数类——熵确实降了,敏感度归零。系统性地在钼靶跨域设置下复现并刻画这一失效模式(何时发生、与患病率/批大小/适应步数的关系)。
2. **方法**:用钼靶固有结构做测试时自监督,替代熵。关键设计:**并非所有数据集/检查都有 CC 视角**(mini-MIAS 纯 MLO;早期 NHS 筛查轮次单视角 MLO;RSNA 中有缺视角检查),因此一致性信号做成**按可用性优雅降级的层级**,有什么用什么:
   - **L1 同侧 CC/MLO 一致性**(最强):检查内两视角齐全时,同一乳房的恶性预测应一致(examination-level consistency loss);
   - **L2 双侧同视角分布对齐**:纯 MLO 检查中左右乳 MLO 仍成对。注意**左右不对称本身是恶性线索**,不能做逐例硬约束(会抹平真癌);改用队列级正则——癌症左右发生率近似对称,故适应后左乳与右乳分数的边缘分布应对齐;
   - **L3 增强自一致性**(MEMO 式):单图对多种增强的预测应一致,永远可用,作保底;
   - **L4 患病率先验正则**:适应后整体预测阳性率贴近筛查患病率,永远可用,兼作防熵崩塌兜底;
   - 各层之上叠加 BN 统计对齐 / 源域特征统计对齐作为稳定器。缺视角的检查按检查级掩码降级到可用层。

**为什么站得住**:一致性信号不依赖类别分布,天然回避不平衡坑;CC/MLO 与双侧结构是 mammo 独有,通用 DA 文章覆盖不到;降级层级让"缺视角"从方法失效场景变成消融刻度;部署场景真实(医院换新机器,无标签)。

### A′(MLO-only 变体,当前首选):重复 MLO 分歧作为无标签 OOD 信号 + 适应目标

**适用设定**:目标域检查可能完全没有 CC,同一乳房只有多张 MLO(重拍/分区拼接)。CC/MLO 配对(L1)整体不可用。

**核心洞察**:同一乳房的多张 MLO 是真实世界的 test-time augmentation——摆位/压迫/曝光的自然变化正是模型本该不变的扰动。源域上模型对重复 MLO 的预测应一致;进入 OOD 域时这种一致性最先破碎。同一信号双用:

1. **OOD 检测 / 选择性预测(第一步,独立成立)**:
   - 检查级"重复视角不稳定度" = 同乳房各 MLO 预测分数的方差(或病灶级:检测框/CAM 跨图不一致度)。无标签、无需源数据、逐检查可算。
   - 逐例用法:不稳定度高 → 弃权/转人工(risk–coverage 曲线);
   - 站点级用法:平均不稳定度上升 → 域漂移报警(部署监控)。
   - 对比基线:Mahalanobis、能量分数、kNN、MSP、深度集成分歧。卖点:测的是"模型在该病人上是否可靠",而非"图像像不像训练集"(后者会把致密乳腺误报为 OOD)。
2. **测试时适应(第二步)**:最小化同乳房 MLO 间预测不一致(仅更新 norm 层),叠加左右乳队列级分布对齐(L2)与患病率先验(L4)。故事线:不稳定度诊断偏移 → 作为目标被优化 → 验证"不稳定度下降 ↔ 真实错误率下降"。

**关键坑(第一个 due diligence)**:多 MLO 的成因必须先分类——
- 重拍/摆位重复:覆盖同一解剖,一致性约束成立;
- 大乳房分区拼接:覆盖不同解剖,病灶只在其一,强行一致会抹掉真癌。
用乳腺掩码配准 + IoU 区分"重复对"与"拼接对";拼接对只做检查级 max 聚合,不进一致性 loss。先在私有数据上统计两类占比,决定信号可用量。

**验证方案**:用 VinDr/RSNA 人为丢弃 CC 构造受控 MLO-only 跨域基准(可扫描每乳房 MLO 张数),私有数据作真实案例研究;目标域标签只用于评测。核心验证点:重复视角不稳定度与逐例错误率的相关性。
**风险分层**:即使 TTA 增益有限,第一步单独可成文("MLO-only 筛查部署的无标签可靠性监控")。

### A″(当前主线):数据集级偏移——厂商后处理随机化 + 数据集级测试时重校准

**设定**:训练集与测试集是不同数据集(不同设备/厂商/站点/后处理协议),即最经典的 leave-one-dataset-out 跨域。

**关键事实**:mammo 数据集级偏移的大头不是探测器物理,而是各厂商 "for presentation" 后处理(unsharp masking、局部对比度增强、gamma/LUT、降噪)——而这个空间**可以显式参数化**(十几个参数)。

**方法(两端各一个模块):**

1. **训练端·厂商后处理模拟增强(域泛化)**:把各厂商 pipeline 组件参数化为可采样的增强族,训练时每图随机采样一套参数,逼模型对"任何合理的后处理"不变。相对 GIN/RandConv/FDA 的卖点:增强空间贴着真实物理,不浪费容量对抗现实中不存在的风格。
2. **测试端·数据集级无标签重校准(利用手里有整个目标数据集的优势)**:
   - 全量目标数据重估 BN 统计;
   - **密度分层特征分布对齐**(mammo 特有设计):目标人群密度分布可能真实不同,全局硬对齐会把人群差异当设备差异抹掉;按 BI-RADS 密度分层对齐,只消设备、不动人群;
   - 患病率先验重校准阈值:解决"AUC 尚可但工作点漂移"的筛查痛点。

**验证设计**:
- 主实验:leave-one-dataset-out(VinDr / CMMD / RSNA / INbreast 轮流留出)。
- **控制实验(亮点)**:VinDr 内部含多厂商机器 → 数据集内 leave-one-vendor-out = 人群不变、纯设备偏移;与跨数据集(设备+人群混合)对比即可量化两种偏移各自贡献——原 B 方案的解耦分析自动成为本方案一章。
- 指标:AUC、sensitivity@fixed specificity、ECE(校准崩坏常比排序退化严重,是临床说服力所在)。

**风险与兜底**:厂商 pipeline 是黑箱,模拟器只能按公开文献逆向近似;若不够逼真,训练端退到 FDA/直方图族,**密度分层对齐 + 阈值重校准两个模块自身有独立新颖性**,故事仍成立。数据集级 OOD *检测*(drift detection)体量小,作附加模块不作主贡献。

### B:采集偏移 vs 人群偏移的解耦分析

用 EMBED(同一机构、Hologic+GE、黑人/白人比例均衡)构造 2×2 对照:

| | 同设备 | 换设备 |
|---|---|---|
| **同人群** | 基线 | 纯采集偏移 |
| **换人群** | 纯人群偏移 | 混合 |

按乳腺密度(BI-RADS A–D)分层,量化两种偏移各自贡献的掉点,并区分"排序退化"与"校准退化"。结论指导对策选择:图像标准化(治采集)vs 阈值重校准(治人群)。偏 analysis paper,适合 Radiology: AI / MedIA / MICCAI。

### C:基础模型时代的域偏移再审视

评测 Mammo-CLIP、MIRAI、DINOv2/RadImageNet 特征 + 线性探针在跨域矩阵下的表现;若仍掉点,用 LoRA/线性头做 few-shot 目标域适应,画**目标域标注样本量 → 性能恢复率**曲线。贡献偏评测,但对实际部署最有指导意义,可作为 A 的扩展章节。

三者关系:A 为主干;B 的解耦实验可作 A 的动机章节;C 可作 A 的"基础模型也不能免疫"论据。

### D(当前主线):MammOOD——采集偏移下的 OOD 检测基准 + 类型化分诊

**术语对齐**:OOD 检测 = 识别并拒判分布外样本(本方案);OOD 泛化 = 模型在分布外不掉点(A″)。两者可作一篇文章的上下半场,主贡献选其一。

**任务定义**:ID = 训练数据集;部署时逐图/逐检查输出 OOD 分数,超阈值 → 拒判/转人工。不同设备来源的各公开数据集即天然 OOD 测试材料。

**三个贡献点(难度递进):**

1. **基准(保底)**:构造严重度分级的 OOD 谱系——
   - near-OOD:同厂商异站点 → 异厂商(CMMD、INbreast、RSNA 按厂商拆分);
   - far-OOD:数字化胶片(CBIS-DDSM)、DBT 合成 2D;
   - garbage-OOD:胸片/其他部位(健全性检查)。
   系统评测 MSP、Energy、Mahalanobis、kNN、ViM、深度集成、MC-dropout。
2. **关键发现(预期负结果,批判性核心)**:特征距离类方法把致密乳腺等真实人群差异误报为 OOD,而危险的近域设备偏移检不出;OOD 分数与实际诊断错误相关性弱——**"检测到 OOD"≠"模型会错"**,用 risk–coverage 曲线钉死。
3. **方法(轻量)·类型化 OOD 分诊**:三个正交分数——
   - **风格分数**(频域/直方图统计):采集/设备偏移;
   - **语义分数**(特征空间距离):内容异常;
   - **不稳定度分数**(测试时施加后处理风格扰动,预测抖动):直接预测"模型在此例上会不会错"。
   组合成动作表:风格 OOD 且稳定 → 重校准继续用;风格 OOD 且不稳定 → 拒判;语义 OOD → 拒判并查输入;正常 → 放行。**输出动作而非笼统分数**,是与通用 OOD 文章的差异点;"重校准"分支衔接 A″ 的测试端模块。

**指标**:OOD AUROC / FPR@95(标配)+ **risk–coverage 曲线**(主推:拒判 x% 换来多少安全,临床唯一关心的量)。

**可行性**:全公开数据;训一个 backbone + 评测现成分数,方法部分轻;约 3 个月出初稿;目标 MICCAI/MIDL。

### E(当前主线):域专家混合 + 留一域元学习可信度路由 + 共识蒸馏

**设定**:N=5 个源数据集各训一个专家模型,2 个数据集留作 OOD;目标域无标签。

**一句话**:用"留一个源假装 OOD"元学习一个路由器,学会预测每个专家在什么域上可信;真 OOD 来了按预测可信度加权融合,再共识蒸馏出单模型。

**阶段 1 · 元训练路由器(核心创新)**
- 5 源轮流留一当"假 OOD",其余 4 专家在其上产生**逐例对错记录**;
- 域描述子 = 设备指纹(BN 特征统计、频域/直方图签名)+ 人群指纹(乳腺密度分布);
- 训练可信度预测器 g:(描述子, 专家) → 预期错误率。**逐例粒度**监督(几万条),而非数据集粒度(仅 5 条);不够再用后处理风格扰动造伪域插值。

**阶段 2 · OOD 部署(无标签)**
- 各专家 BN 统计重估 → 算目标描述子 → g 输出各专家可信度 → 归一化为融合权重,加权集成。
- 与手工风格距离加权的差异:相似度→可信度的映射是**学出来的**;描述子含双指纹,路由隐式区分"设备偏移找同设备专家 / 人群偏移找同人群专家"(消融:分别拆掉两类描述子)。

**阶段 3 · 共识蒸馏(可选)**
- 高共识病例打伪标签(叠加患病率先验,防不平衡下伪标签全阴),蒸馏成单个部署模型,推理成本回到 1×。

**基线与命题**:pooled ERM(5 集合并训)、均匀集成、oracle 最优单专家、SWAD/MIRO、风格距离手工加权。命题:学习路由 > 均匀集成 ≈ pooled ERM > 单专家。
**评测**:5 数据集 leave-2-out 轮换,C(5,2)=10 组合。
**兜底**:OOD 离所有源都远时权重趋于均匀 → 退化为均匀集成 + BN 对齐,不劣于基线;路由权重熵可兼作域漂移报警(衔接 D)。
**Go/No-Go(第一周)**:先跑 pooled ERM vs 均匀集成 vs oracle 单专家。若 oracle 单专家显著高于 pooled(专家各有所长),路由有增益空间;若 pooled 封顶,换故事。多源 DG 文献中 pooled ERM+SWAD 出名难打,此风险必须先验证。
**变体(备选/消融)**:权重空间融合——目标域条件的 model soup 系数搜索(无标签一致性作代理目标),推理零开销。

### E′(当前主线):OOD 域的 Wasserstein 混合表示——泛化界导出的专家融合

**设定同 E**;共享特征空间 φ(冻结 backbone/基础模型特征)中源域分布 μ₁…μ₅,专家 h₁…h₅,源经验风险 ε_k,目标无标签经验分布 μ_T。

**① 几何刻画(核心优化问题)**:在单纯形上求
  λ\* = argmin_{λ∈Δ⁴} W₂(μ_T, Σ_k λ_k μ_k)
——目标域最接近源域的哪个凸组合。sliced-Wasserstein/Sinkhorn 样本估计;λ 用镜像下降/投影梯度;无需目标标签。

**② 理论挂钩(定理)**:由 Wasserstein 域适应泛化界(Redko 等,Lipschitz 损失):
  ε_T(h_λ) ≤ Σ_k λ_k ε_k + C·W₂(μ_T, Σ_k λ_k μ_k) + 余项
→ ①的目标即此界主项:**算法 = 直接最小化目标风险上界**,非启发式。

**③ λ 的三重用途**:
1. 输出融合:ŷ = Σ λ_k\* h_k(x)(主方法);
2. 权重空间融合:λ\* 作 model soup 系数,推理零开销(变体/消融);
3. **残差 d\* = W₂(μ_T, Σλ\*μ_k) = 目标域到源域凸包的距离**——有几何意义的 OOD 度量:d\* 小则可被源组合覆盖,d\* 大则真分布外 → 拒判/漂移报警。

**④ 可选保证**:密度比加权 conformal prediction(协变量偏移加权共形)给 OOD 集上有限样本覆盖保证。

**两个技术点(兼贡献点)**:
- **Label-shift 校正的 OT**:患病率跨域不同,先用 BBSE/患病率先验估目标类比例、重加权源分布再算 W₂;
- **条件 OT 防混杂**:按乳腺密度分层求 λ 再聚合(条件 Wasserstein),避免把人群差异计入设备距离。

**论文结构**:定理(附录证明,基于现有界改写)— 算法(单纯形凸组合优化)— 实验(leave-2-out,10 组合)。
**基线**:uniform ensemble、pooled ERM、oracle 单专家、风格距离加权、方案 E 的元学习路由(学习式 vs 理论式对照)。
**风险**:界可能松(DA 理论通病,以"界作为设计原则"辩护);go/no-go 同 E(oracle 单专家 vs pooled ERM 先行验证)。

### F(当前主线):域条件归一化桥——测试时解 ODE 把 OOD 图像洗回规范域

**文献格局(2026-08 查证)**:
- 输入侧 ODE 适应范式:DDA(CVPR 2023, arXiv:2207.03442)——扩散把 OOD 输入投影回源分布,分类器冻结;仅自然图像。
- SB 无配对医学协调已落地:OCT(NeurIPS 2025 解剖引导潜空间 SB)、CBCT→CT(解剖保持 SB)、UNSB(arXiv:2305.15086)、BlindHarmony(流模型盲协调 MRI, arXiv:2305.10732)。
- 近邻:MedShift(arXiv:2508.21435)类条件 flow matching 做 X 光域翻译(仿真→真实),未做乳腺/未见域。
- PF-ODE 精确似然 OOD 检测成熟,表征空间效果最好。**例文**:Ding et al., "Revisiting Likelihood-Based OOD Detection by Modeling Representations", SCIA 2025, arXiv:2504.07793——预训练编码器特征上训 RDM(表征扩散模型),RK45 解 PF-ODE + 瞬时变量替换公式算精确 log p(z) 作 OOD 分数(散度项 Skilling–Hutchinson 迹估计);像素空间似然失灵(Nalisnick 现象),表征空间追平 SOTA。数学源头:Song et al., Score-Based Generative Modeling through SDEs, ICLR 2021。同族:CNF 局部轨迹诊断 OOD(arXiv:2606.00684)。**V2 变体即以此为模板**:mammo backbone 特征 + 多源条件 RDM(ConRDM)+ 路径动能作偏移严重度。
- GDA 理论:中间域沿 Wasserstein 测地线(GOAT;GDA Theory arXiv:2310.13852;梯度流 GDA, ICLR 2024)。
- **Mammo 空位**:仅 BN 适应(DoSReMC, arXiv:2508.15452)与老式对抗 DA;MammoFlow(arXiv:2606.28537)是视角合成非域偏移。桥/ODE 式跨厂商协调在 mammo 为空白。
- **CLIPTTA(NeurIPS 2025, arXiv:2507.14312)**:熵最小化 TTA 与 CLIP 对比预训练目标不对齐 → 伪标签漂移/类塌缩;改用软对比损失(损失形状与预训练一致),梯度分析证明 batch 内互斥项防塌缩;OCE 损失做开集 TTA(边适应边推开 OOD)。**接口**:①坐实"熵 TTA 结构性缺陷"论据(与本项目低患病率失效分析互补);②新路线:Mammo-CLIP + 软对比 TTA + 患病率感知 batch 设计(极端不平衡下 batch 互斥项行为是开放问题);③OCE 思想衔接类型化分诊。

**V1(主)·图像空间归一化桥**:
- 5 源域训**域条件 flow matching / Schrödinger 桥**:速度场 v(x,t,z_d) 把各源域运往共同规范域(hub);z_d = 由域统计量(频域/直方图/BN 统计)编码的**连续域嵌入**,未见域取嵌入插值/外推 → 解 PF-ODE 完成厂商归一化;分类器只在规范域训练、永远冻结。
- 数学部件:flow matching 目标、PF-ODE 求解、熵正则 OT ≍ SB 等价性(理论章)。
- **Mammo 核心难点兼贡献**:微钙化(数十微米)易被生成翻译抹除 → 高频保持约束/病灶感知引导,须以微钙化检测 AUC 单独验证。
- **白送的 OOD 度量**:同一模型给 PF-ODE 精确似然(逐图 OOD 分数)+ ODE 路径动能(域偏移严重度)。

**V2(轻量变体/算力兜底)·特征空间梯度流**:冻结 backbone,特征上训 score 模型,OOD 特征沿粒子 ODE dx/dt = ∇log p_src(x) 流回源流形,分类头不动。Fokker–Planck/JKO 框架;与 E′ 衔接(流终点 = λ\*-混合)。图像空间 2–4K 分辨率算力昂贵时,此为现实主线;表征空间似然类方法文献上更强。

**V3(可叠加扩展)·测地线渐进自训练**:桥模型生成 GDA 理论要求的测地线中间域,K 步自训练,误差界随步长 W 距离累积(GOAT/GDA 理论现成)——生成模型补上"中间域从哪来",理论与生成闭环。

**推荐组合**:V1 主文章,V2 消融兼兜底,V3 扩展章节。

**策略定位(v8 讨论:生成分布 vs ODE vs 流形)**:三者非并列——似然是目标、ODE 是引擎、流形是几何视角。结论:**流形分解的 ODE 似然**。
- 观察:设备偏移 = 样本被沿法向推离源流形(低层纹理,早期扩散时间/score 范数可抓);人群/语义偏移 = 样本在流形上但落于低密度区(晚期轨迹/流形上密度可抓)。
- 方法:解同一条增广 PF-ODE,把 log p 沿轨迹按时间尺度/法-切向投影**分解为"离流形分量"(风格/设备)与"流形密度分量"(语义/人群)**,即似然分解定理 + 免费副产品。
- 闭环:离流形分量高 → 归一化桥/重校准;流形密度低 → 拒判(衔接 D 的类型化分诊)。
- 实验命题:两分量分别与"换设备"(VinDr 内换厂商)、"换人群"(密度重采样)对照实验对齐,而 kNN/Mahalanobis/单一似然无法区分二者——差异化战场,不在总 AUROC 硬拼。
- 执行顺序:先跑 kNN/Mahalanobis 几何基线(兼 go/no-go:若已完美分开 OOD 集,故事压"分解与归因"而非"检测"),再上 ODE 分解版。
**Go/No-Go**:512 分辨率 + 两个域先验证(a)归一化后冻结分类器跨域恢复几个点;(b)微钙化 AUC 是否掉。结果决定走 V1 还是退守 V2。

## 4. 实验设计(A 方案)

### 4.1 最小可行实验(MVE,2–3 周)

1. VinDr 训 EfficientNet-B2 / ConvNeXt-T 级别检查级分类器(单视角 + 双视角 late fusion 两版)。
2. 零适应直接测 CMMD、RSNA、INbreast:记录 AUC、sensitivity@90% specificity、ECE。
3. 跑 TENT / BN-adapt:复现"熵最小化→敏感度崩塌"。这是全文的 motivating evidence。
4. 换上多视角一致性 TTA,看敏感度能否恢复。

### 4.2 完整实验矩阵

- **跨域方向**:VinDr↔CMMD↔RSNA↔INbreast(+EMBED 若获批),报告全矩阵而非单方向。
- **Baselines**:
  - 无适应;直方图匹配;Fourier Domain Adaptation(FDA);
  - 训练时增强类:GIN、RandConv、风格增强;
  - TTA 类:BN-adapt、TENT、T3A、MEMO、SAR;
  - 上界:目标域少量标签微调(oracle 参照)。
- **指标**:AUC、pAUC(高特异度区)、sensitivity@fixed specificity、ECE / 校准曲线、适应后的预测阳性率漂移。
- **消融**:一致性 loss vs 熵;**信号可用性阶梯**(仅 L3/L4 → +L2 → +L1,量化每层信号带来的恢复量;并模拟随机丢弃 CC 视角的比例扫描);有无 BN 对齐;有无 prevalence 正则;批大小与流式(online)设置;检查级 vs 图像级适应。
- **极端降级压力测试**:mini-MIAS(纯 MLO + 数字化胶片)不进主实验,仅作 L1 完全不可用场景的展示点。
- **分层分析**:按乳腺密度、按病灶类型(肿块 vs 钙化)分层看掉点与恢复。

## 5. 风险与备案

| 风险 | 备案 |
|---|---|
| 多视角一致性信号太弱,单独用不收敛 | 与 BN 统计对齐/源统计对齐组合;退一步做 episodic(每检查独立适应)而非累积 |
| 目标域缺 CC 视角(纯 MLO 数据集/缺视角检查) | 信号层级 L1→L4 优雅降级(见 2.A);消融中量化各层贡献,把缺视角变成实验刻度而非失效场景 |
| 多 MLO 实为分区拼接而非重复,一致性约束抹掉真癌 | 乳腺掩码配准 + IoU 先分"重复对/拼接对";拼接对只做 max 聚合;先统计私有数据两类占比 |
| 重复 MLO 数量太少,不稳定度估计噪声大 | 病灶级不一致度(检测框/CAM)信息量高于单一分数方差;与特征距离类 OOD 分数融合 |
| CMMD 全为活检病例,患病率不真实 | 按检查级重采样模拟筛查患病率;主结果压在 RSNA(真实患病率)上 |
| 高分辨率算力开销 | 1536–2048 长边缩放;TTA 只更新 norm 层参数,开销可控 |
| "TTA 失效"已被别人指出 | 检索确认:通用不平衡 TTA 有零星工作,但 mammo 筛查场景 + 多视角替代方案未见;把领域特异性做深 |
| 与 Mammo-CLIP 等撞车 | 把基础模型作为被适应的 backbone 之一纳入实验,变竞争为素材 |
