# 乳腺钼靶(Mammography)域偏移研究构思

> 状态:构思稿 v1(2026-08)
> 一句话:筛查场景下现有测试时适应(TTA)方法的失效分析 + 利用钼靶多视角结构做一致性驱动的无标签域适应。
> **v2 更新**:目标数据可能完全没有 CC、同一乳房只有多张 MLO → 首选方案调整为 A′(重复 MLO 分歧作为无标签 OOD 信号 + 适应目标)。

## 1. 问题背景

钼靶癌症检测/分类模型在跨域部署时性能显著下降,偏移来源可分为两类:

- **采集偏移(acquisition shift)**:厂商(Hologic / GE / Siemens / Fuji / IMS)、探测器、剂量、压迫厚度,尤其是各家 "for presentation" 后处理差异巨大;数字化胶片(DDSM)与 FFDM、DBT 合成 2D(C-View)差异更大。
- **人群偏移(population shift)**:乳腺密度分布随人种/年龄差异明显(亚洲女性致密型比例高),患病率与病灶谱系也不同。

已知经验现象:跨域时 AUC 掉 5–15 点;**校准崩得比排序更狠**——AUC 尚可但工作点阈值失效,对以"召回率达标"为硬约束的筛查流程是致命的。

## 2. 三个候选切入点

### A(推荐):多视角一致性驱动的测试时适应 + TTA 失效分析

**两个贡献点:**

1. **失效分析**:筛查数据癌症患病率 <1%。TENT/MEMO 等基于熵最小化的 TTA 在极端类别不平衡下会把全部样本推向多数类——熵确实降了,敏感度归零。系统性地在钼靶跨域设置下复现并刻画这一失效模式(何时发生、与患病率/批大小/适应步数的关系)。
2. **方法**:用钼靶固有结构做测试时自监督,替代熵。关键设计:**并非所有数据集/检查都有 CC 视角**(mini-MIAS 纯 MLO;早期 NHS 筛查轮次单视角 MLO;RSNA 中有缺视角检查),因此一致性信号做成**按可用性优雅降级的层级**,有什么用什么:
   - **L1 同侧 CC/MLO 一致性**(最强):检查内两视角齐全时,同一乳房的恶性预测应一致(examination-level consistency loss);
   - **L2 双侧同视角分布对齐**:纯 MLO 检查中左右乳 MLO 仍成对。注意**左右不对称本身是恶性线索**,不能做逐例硬约束(会抹平真癌);改用队列级正则——癌症左右发生率近似对称,故适应后左乳与右乳分数的边缘分布应对齐;
   - **L3 增强自一致性**(MEMO 式):单图对多种增强的预测应一致,永远可用,作保底;
   - **L4 患病率先验正则**:适应后整体预测阳性率贴近筛查患病率,永远可用,兼作防熵崩塌兜底;
   - 各层之上叠加 BN 统计对齐 / 源域特征统计对齐作为稳定器。缺视角的检查按检查级掩码降级到可用层。

**为什么站得住**:一致性信号不依赖类别分布,天然回避不平衡坑;CC/MLO 与双侧结构是 mammo 独有,通用 DA 文章覆盖不到;降级层级让"缺视角"从方法失效场景变成消融刻度;部署场景真实(医院换新机器,无标签)。

### A′(MLO-only 变体,当前首选):重复 MLO 分歧作为无标签 OOD 信号 + 适应目标

**适用设定**:目标域检查可能完全没有 CC,同一乳房只有多张 MLO(重拍/分区拼接)。CC/MLO 配对(L1)整体不可用。

**核心洞察**:同一乳房的多张 MLO 是真实世界的 test-time augmentation——摆位/压迫/曝光的自然变化正是模型本该不变的扰动。源域上模型对重复 MLO 的预测应一致;进入 OOD 域时这种一致性最先破碎。同一信号双用:

1. **OOD 检测 / 选择性预测(第一步,独立成立)**:
   - 检查级"重复视角不稳定度" = 同乳房各 MLO 预测分数的方差(或病灶级:检测框/CAM 跨图不一致度)。无标签、无需源数据、逐检查可算。
   - 逐例用法:不稳定度高 → 弃权/转人工(risk–coverage 曲线);
   - 站点级用法:平均不稳定度上升 → 域漂移报警(部署监控)。
   - 对比基线:Mahalanobis、能量分数、kNN、MSP、深度集成分歧。卖点:测的是"模型在该病人上是否可靠",而非"图像像不像训练集"(后者会把致密乳腺误报为 OOD)。
2. **测试时适应(第二步)**:最小化同乳房 MLO 间预测不一致(仅更新 norm 层),叠加左右乳队列级分布对齐(L2)与患病率先验(L4)。故事线:不稳定度诊断偏移 → 作为目标被优化 → 验证"不稳定度下降 ↔ 真实错误率下降"。

**关键坑(第一个 due diligence)**:多 MLO 的成因必须先分类——
- 重拍/摆位重复:覆盖同一解剖,一致性约束成立;
- 大乳房分区拼接:覆盖不同解剖,病灶只在其一,强行一致会抹掉真癌。
用乳腺掩码配准 + IoU 区分"重复对"与"拼接对";拼接对只做检查级 max 聚合,不进一致性 loss。先在私有数据上统计两类占比,决定信号可用量。

**验证方案**:用 VinDr/RSNA 人为丢弃 CC 构造受控 MLO-only 跨域基准(可扫描每乳房 MLO 张数),私有数据作真实案例研究;目标域标签只用于评测。核心验证点:重复视角不稳定度与逐例错误率的相关性。
**风险分层**:即使 TTA 增益有限,第一步单独可成文("MLO-only 筛查部署的无标签可靠性监控")。

### B:采集偏移 vs 人群偏移的解耦分析

用 EMBED(同一机构、Hologic+GE、黑人/白人比例均衡)构造 2×2 对照:

| | 同设备 | 换设备 |
|---|---|---|
| **同人群** | 基线 | 纯采集偏移 |
| **换人群** | 纯人群偏移 | 混合 |

按乳腺密度(BI-RADS A–D)分层,量化两种偏移各自贡献的掉点,并区分"排序退化"与"校准退化"。结论指导对策选择:图像标准化(治采集)vs 阈值重校准(治人群)。偏 analysis paper,适合 Radiology: AI / MedIA / MICCAI。

### C:基础模型时代的域偏移再审视

评测 Mammo-CLIP、MIRAI、DINOv2/RadImageNet 特征 + 线性探针在跨域矩阵下的表现;若仍掉点,用 LoRA/线性头做 few-shot 目标域适应,画**目标域标注样本量 → 性能恢复率**曲线。贡献偏评测,但对实际部署最有指导意义,可作为 A 的扩展章节。

三者关系:A 为主干;B 的解耦实验可作 A 的动机章节;C 可作 A 的"基础模型也不能免疫"论据。

## 4. 实验设计(A 方案)

### 4.1 最小可行实验(MVE,2–3 周)

1. VinDr 训 EfficientNet-B2 / ConvNeXt-T 级别检查级分类器(单视角 + 双视角 late fusion 两版)。
2. 零适应直接测 CMMD、RSNA、INbreast:记录 AUC、sensitivity@90% specificity、ECE。
3. 跑 TENT / BN-adapt:复现"熵最小化→敏感度崩塌"。这是全文的 motivating evidence。
4. 换上多视角一致性 TTA,看敏感度能否恢复。

### 4.2 完整实验矩阵

- **跨域方向**:VinDr↔CMMD↔RSNA↔INbreast(+EMBED 若获批),报告全矩阵而非单方向。
- **Baselines**:
  - 无适应;直方图匹配;Fourier Domain Adaptation(FDA);
  - 训练时增强类:GIN、RandConv、风格增强;
  - TTA 类:BN-adapt、TENT、T3A、MEMO、SAR;
  - 上界:目标域少量标签微调(oracle 参照)。
- **指标**:AUC、pAUC(高特异度区)、sensitivity@fixed specificity、ECE / 校准曲线、适应后的预测阳性率漂移。
- **消融**:一致性 loss vs 熵;**信号可用性阶梯**(仅 L3/L4 → +L2 → +L1,量化每层信号带来的恢复量;并模拟随机丢弃 CC 视角的比例扫描);有无 BN 对齐;有无 prevalence 正则;批大小与流式(online)设置;检查级 vs 图像级适应。
- **极端降级压力测试**:mini-MIAS(纯 MLO + 数字化胶片)不进主实验,仅作 L1 完全不可用场景的展示点。
- **分层分析**:按乳腺密度、按病灶类型(肿块 vs 钙化)分层看掉点与恢复。

## 5. 风险与备案

| 风险 | 备案 |
|---|---|
| 多视角一致性信号太弱,单独用不收敛 | 与 BN 统计对齐/源统计对齐组合;退一步做 episodic(每检查独立适应)而非累积 |
| 目标域缺 CC 视角(纯 MLO 数据集/缺视角检查) | 信号层级 L1→L4 优雅降级(见 2.A);消融中量化各层贡献,把缺视角变成实验刻度而非失效场景 |
| 多 MLO 实为分区拼接而非重复,一致性约束抹掉真癌 | 乳腺掩码配准 + IoU 先分"重复对/拼接对";拼接对只做 max 聚合;先统计私有数据两类占比 |
| 重复 MLO 数量太少,不稳定度估计噪声大 | 病灶级不一致度(检测框/CAM)信息量高于单一分数方差;与特征距离类 OOD 分数融合 |
| CMMD 全为活检病例,患病率不真实 | 按检查级重采样模拟筛查患病率;主结果压在 RSNA(真实患病率)上 |
| 高分辨率算力开销 | 1536–2048 长边缩放;TTA 只更新 norm 层参数,开销可控 |
| "TTA 失效"已被别人指出 | 检索确认:通用不平衡 TTA 有零星工作,但 mammo 筛查场景 + 多视角替代方案未见;把领域特异性做深 |
| 与 Mammo-CLIP 等撞车 | 把基础模型作为被适应的 backbone 之一纳入实验,变竞争为素材 |
