# 乳腺钼靶(Mammography)域偏移研究构思

> 状态:构思稿 v1(2026-08)
> 一句话:筛查场景下现有测试时适应(TTA)方法的失效分析 + 利用钼靶多视角结构做一致性驱动的无标签域适应。

## 1. 问题背景

钼靶癌症检测/分类模型在跨域部署时性能显著下降,偏移来源可分为两类:

- **采集偏移(acquisition shift)**:厂商(Hologic / GE / Siemens / Fuji / IMS)、探测器、剂量、压迫厚度,尤其是各家 "for presentation" 后处理差异巨大;数字化胶片(DDSM)与 FFDM、DBT 合成 2D(C-View)差异更大。
- **人群偏移(population shift)**:乳腺密度分布随人种/年龄差异明显(亚洲女性致密型比例高),患病率与病灶谱系也不同。

已知经验现象:跨域时 AUC 掉 5–15 点;**校准崩得比排序更狠**——AUC 尚可但工作点阈值失效,对以"召回率达标"为硬约束的筛查流程是致命的。

## 2. 三个候选切入点

### A(推荐):多视角一致性驱动的测试时适应 + TTA 失效分析

**两个贡献点:**

1. **失效分析**:筛查数据癌症患病率 <1%。TENT/MEMO 等基于熵最小化的 TTA 在极端类别不平衡下会把全部样本推向多数类——熵确实降了,敏感度归零。系统性地在钼靶跨域设置下复现并刻画这一失效模式(何时发生、与患病率/批大小/适应步数的关系)。
2. **方法**:用钼靶固有结构做测试时自监督,替代熵:
   - 同一乳房 CC / MLO 两视角的恶性预测一致性(examination-level consistency loss);
   - 左右对侧对称性作为软参照(对侧不对称本身是恶性线索,故只作正则不作硬约束);
   - 叠加 BN 统计对齐 / 源域特征统计对齐作为稳定器;
   - 可选:prevalence-aware 正则(约束适应后预测阳性率接近先验患病率)。

**为什么站得住**:一致性信号不依赖类别分布,天然回避不平衡坑;CC/MLO 结构是 mammo 独有,通用 DA 文章覆盖不到;部署场景真实(医院换新机器,无标签)。

### B:采集偏移 vs 人群偏移的解耦分析

用 EMBED(同一机构、Hologic+GE、黑人/白人比例均衡)构造 2×2 对照:

| | 同设备 | 换设备 |
|---|---|---|
| **同人群** | 基线 | 纯采集偏移 |
| **换人群** | 纯人群偏移 | 混合 |

按乳腺密度(BI-RADS A–D)分层,量化两种偏移各自贡献的掉点,并区分"排序退化"与"校准退化"。结论指导对策选择:图像标准化(治采集)vs 阈值重校准(治人群)。偏 analysis paper,适合 Radiology: AI / MedIA / MICCAI。

### C:基础模型时代的域偏移再审视

评测 Mammo-CLIP、MIRAI、DINOv2/RadImageNet 特征 + 线性探针在跨域矩阵下的表现;若仍掉点,用 LoRA/线性头做 few-shot 目标域适应,画**目标域标注样本量 → 性能恢复率**曲线。贡献偏评测,但对实际部署最有指导意义,可作为 A 的扩展章节。

三者关系:A 为主干;B 的解耦实验可作 A 的动机章节;C 可作 A 的"基础模型也不能免疫"论据。

## 4. 实验设计(A 方案)

### 4.1 最小可行实验(MVE,2–3 周)

1. VinDr 训 EfficientNet-B2 / ConvNeXt-T 级别检查级分类器(单视角 + 双视角 late fusion 两版)。
2. 零适应直接测 CMMD、RSNA、INbreast:记录 AUC、sensitivity@90% specificity、ECE。
3. 跑 TENT / BN-adapt:复现"熵最小化→敏感度崩塌"。这是全文的 motivating evidence。
4. 换上多视角一致性 TTA,看敏感度能否恢复。

### 4.2 完整实验矩阵

- **跨域方向**:VinDr↔CMMD↔RSNA↔INbreast(+EMBED 若获批),报告全矩阵而非单方向。
- **Baselines**:
  - 无适应;直方图匹配;Fourier Domain Adaptation(FDA);
  - 训练时增强类:GIN、RandConv、风格增强;
  - TTA 类:BN-adapt、TENT、T3A、MEMO、SAR;
  - 上界:目标域少量标签微调(oracle 参照)。
- **指标**:AUC、pAUC(高特异度区)、sensitivity@fixed specificity、ECE / 校准曲线、适应后的预测阳性率漂移。
- **消融**:一致性 loss vs 熵;有无 BN 对齐;有无 prevalence 正则;批大小与流式(online)设置;检查级 vs 图像级适应。
- **分层分析**:按乳腺密度、按病灶类型(肿块 vs 钙化)分层看掉点与恢复。

## 5. 风险与备案

| 风险 | 备案 |
|---|---|
| 多视角一致性信号太弱,单独用不收敛 | 与 BN 统计对齐/源统计对齐组合;退一步做 episodic(每检查独立适应)而非累积 |
| CMMD 全为活检病例,患病率不真实 | 按检查级重采样模拟筛查患病率;主结果压在 RSNA(真实患病率)上 |
| 高分辨率算力开销 | 1536–2048 长边缩放;TTA 只更新 norm 层参数,开销可控 |
| "TTA 失效"已被别人指出 | 检索确认:通用不平衡 TTA 有零星工作,但 mammo 筛查场景 + 多视角替代方案未见;把领域特异性做深 |
| 与 Mammo-CLIP 等撞车 | 把基础模型作为被适应的 backbone 之一纳入实验,变竞争为素材 |

## 6. 里程碑

1. 第 1–3 周:MVE(4.1),拿到失效证据。
2. 第 4–6 周:多视角一致性 TTA 成型 + 主要 baseline。
3. 第 7–9 周:全矩阵 + 消融 + 分层分析;同步申请 EMBED。
4. 第 10–12 周:写作。目标 venue:MICCAI / MIDL / IEEE TMI / MedIA(按结果强度定)。
